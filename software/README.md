# Software

Desktop interface for controlling the Carrier-Wave function generator.

> 🚧 Coming soon — desktop software is planned but not yet implemented.

This software will provide a user-friendly interface for configuring and controlling the function generator from a computer. It will communicate with the device over USB, allowing real-time adjustment of waveform parameters without relying solely on onboard controls.

## Planned Features

- Real-time waveform control (waveform, frequency, amplitude, offset)
- Preset saving and loading
- Device communication over USB / serial
- Optional waveform visualization
